# TEMPLATE BUKU TA VERSI 2.0

Template dokumen LaTeX siap pakai yang disesuaikan dengan pedoman penulisan Tugas Akhir di Teknik Fisika, Institut Teknologi Sumatera.

## 🚀 Cara Penggunaan

### Menggunakan Overleaf
1. Download file **ZIP** (`Open Template-TA-TF-Itera-2_0.zip` -> `Download Raw`).
2. Masuk ke [Overleaf](https://www.overleaf.com), pilih **New Project** -> **Upload Project**.
3. Pastikan compiler diatur ke **pdfLaTeX**.
4. Set main document ke `main.tex`.

## 📝 Panduan Pengisian Dokumen
1. **`identitas.tex`**: Masukkan biodata diri, data pembimbing, dan judul skripsi Anda di sini.
2. **`bab/`**: Tulis isi dokumen Anda pada file `bab1.tex` sampai `bab5.tex`.
3. **`pustaka.bib`**: Tambahkan daftar referensi/pustaka dalam format BibTeX.
4. **`gambar/`**: Letakkan semua aset gambar yang digunakan di folder ini.
